# CFPress Custom Forms Plugin (自定义表单插件)

CFPress 平台的官方自定义表单扩展插件，提供可视化表单设计、多语言字段配置、短代码嵌入、侧边栏小工具与自动化防刷提交流水线。

---

## 🌟 核心特性

1. **可视化拖拽/点击表单设计器**:
   - 后台 SPA 专属界面：工具箱 (Toolbox)、中心画布 (Canvas) 与属性检查器 (Inspector)。
   - 支持 9 种基础控件：单行文本 (Text)、多行段落 (Textarea)、邮箱 (Email)、电话 (Phone)、数字 (Number)、下拉选择 (Select)、单选按钮 (Radio)、多选复选框 (Checkbox)、日期选择 (Date)。
   - 字段实时重命名 (Key)、标签 (Label)、占位符 (Placeholder)、必填项控制与动态选项编辑。

2. **多端灵活嵌入**:
   - **短代码嵌入**: 在任何文章、页面或自定义模板正文中输入 `[form id="contact-us"]` 或 `[form slug="booking-inquiry"]` 即可动态展开渲染。
   - **侧边栏小工具 (Widget)**: 在外观 -> 小工具中添加 `plugin.form` 小工具，选择表单标识符，即可展示在网站任意侧边栏或页脚区域。

3. **安全与自动化防刷 (Anti-Spam)**:
   - 内置静默蜜罐技术 (`_cfp_hp`)：真实访客无感知，恶意机器人填入时自动静默丢弃并伪装成功，零误伤拦截垃圾信息。
   - 客户端与服务端双重校验：字段必填项、邮箱合法性正则、数字类型格式等。
   - 访客隐私保护：IP 地址经 SHA-256 加盐单向哈希后入库，记录用户代理 (User-Agent) 便于安全审计。

4. **无 JS / AJAX 双模兼容**:
   - 支持前台无 JS 原生浏览器 `<form method="POST">` 提交，自动 303 PRG (Post-Redirect-Get) 刷新与状态提示。
   - 支持现代前端无刷新 AJAX / Fetch 提交，返回清晰的 JSON 响应。

5. **扩展与生命周期 Hook**:
   - **`formRender`**: 表单 HTML 渲染前触发，允许第三方扩展过滤字段结构、注入自定义 CSS 类或附加字段。
   - **`formSubmit`**: 表单校验通过并入库前触发，支持前置拦截、修改 payload 或数据增强。
   - **`FormSubmitted` (Domain Event)**: 提交入库后由系统发布领域事件，供 Webhook 插件、通知插件（如 Notify）实时转发推送。

6. **纯 D1 免 R2 实时安装**:
   - 插件完全基于 D1 关系型数据库存储表单与提交数据，无需依赖 Cloudflare R2 对象存储即可在本地或生产环境实时上传 ZIP 安装启用。

---

## 🚀 快速开始

### 1. 安装启用
在 CFPress 管理后台 -> 插件 -> 点击“上传插件”，选择 `cfpress-forms.zip` 即可完成安装与数据表初始化。

### 2. 创建表单
进入后台侧边栏 -> **自定义表单 (Custom Forms)** -> 点击“新建表单”，拖入所需字段并保存。

### 3. 在页面嵌入
复制表单列表中提供的短代码：
```text
[form slug="contact-us"]
```
粘贴到任意页面编辑器的内容中保存并发布。

### 4. 查看提交记录
在表单列表中点击对应的“提交记录”按钮，或在后台表单管理中实时查看访客提交的数据详情与时间。
